## 摘要
格子玻尔兹曼方法（LBM）是一种在介观尺度上模拟流体流动的成熟方法。随着摩尔定律的停滞，高性能计算已转向 GPU 加速器，这需要能在不同硬件平台上确保可移植性和效率的编程模型。我们提出 PortLBM，一个基于 SYCL 构建的可扩展便携式 LBM 框架，它将跨平台 GPU 支持与交互式实时可视化集成在一起。PortLBM 支持从卡门涡街、机翼流到多孔介质等多种模拟场景，并且设计为易于通过新算法和后端进行扩展。作为性能可移植性研究的一部分，我们在 NVIDIA、AMD 和 Intel 的当代 GPU 架构上评估了 PortLBM，考察了三种数据布局（流、束和碰撞）和四种算法变体对模拟吞吐量的影响。我们的结果表明，没有单一配置能在所有 GPU 供应商上实现最佳性能，这证实了针对特定系统进行调优的必要性。流布局最大化带宽并在当代 NVIDIA 和 Intel GPU 上表现最佳，而束布局提高了缓存效率并在 AMD GPU 上表现出色。双格子方案实现更高的吞吐量，而单格子方案在内存受限时更可取。我们的工作强调了在日益异构的计算环境中需要适应性强、可移植的 LBM 软件。

## Abstract
The lattice Boltzmann method (LBM) is a well-established approach for simulating fluid flows at the mesoscopic scale. With the stagnation of Moore's law, high-performance computing has shifted toward GPU accelerators, necessitating programming models that ensure both portability and efficiency across diverse hardware platforms.   We present PortLBM, an extensible portable LBM framework built on SYCL that integrates cross-platform GPU support with interactive real-time visualization. PortLBM supports diverse simulation scenarios ranging from Kármán vortex streets and wing flows to porous media, and is designed for easy extension with new algorithms and backends. As part of a performance portability study, we evaluate PortLBM on contemporary GPU architectures from NVIDIA, AMD, and Intel, examining the impact of three data layouts (stream, bundle, and collision) and four algorithmic variants on simulation throughput.   Our results show that no single configuration achieves optimal performance across all GPU vendors, confirming the need for system-specific tuning. The stream layout maximizes bandwidth and performs best on the contemporary NVIDIA and Intel GPUs, while the bundle layout improves cache efficiency and excels on the AMD GPU. Two-lattice schemes achieve higher throughput while one-lattice schemes are preferable under memory constraints. Our work underscores the necessity for adaptable, portable LBM software in increasingly heterogeneous computing environments.
